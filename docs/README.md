# Project Documentation

## Mini Chess AI using Minimax and Alpha-Beta Pruning

This folder contains the project report, screenshots, result tables, and plots.

### Project Objectives

- Generate legal chess moves.
- Evaluate chess positions using material and positional scores.
- Implement depth-limited Minimax.
- Improve Minimax using Alpha-Beta pruning.
- Compare different search depths.
- Compare the number of nodes searched with and without pruning.

### Expected Results

The project will compare:

1. Search depth and playing strength.
2. Minimax and Alpha-Beta pruning.
3. Nodes expanded and execution time.

The final report will be stored as:

`docs/report.pdf`
